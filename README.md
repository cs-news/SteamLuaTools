# SteamLuaTools v1.0

## 📌 О программе

**SteamLuaTools** — программа для автоматической установки и управления **OpenSteamTools**.

Программа создана для замены нерабочей версии SteamTools. Она автоматически устанавливает необходимые файлы в папку Steam, заменяет 3 DLL-файла и создаёт папку:


В эту папку добавляются игровые манифесты для работы SteamTools.

---

## ✨ Возможности

✅ Автоматическая установка OpenSteamTools  
✅ Автоматический поиск папки Steam  
✅ Установка файлов из встроенного ZIP-архива  
✅ Создание папки `config/lua` автоматически

✅ Настройка размера иконки

---

## ⚙️ Установка

1. Запустите программу **от имени администратора**.

2. Нажмите кнопку установки **OpenSteamTools**.

3. Программа автоматически:
   - найдёт папку Steam;
   - заменит необходимые 3 DLL-файла;
   - создаст папку `config/lua`, если её нет.

4. После установки можно использовать SteamTools.

Изменение файлов Steam необходимо только для работы программы.

**SteamLuaTools не изменяет аккаунт Steam, не влияет на игры, сохранения или личные данные пользователя.**

# SteamLuaTools v1.0

## 📌 About

**SteamLuaTools** is a program for automatic installation and management of **OpenSteamTools**.

The program was created to replace the non-working version of SteamTools. It automatically installs the required files into the Steam folder, replaces 3 DLL files, and creates the folder:


This folder is used for adding game manifests required for SteamTools functionality.

---

## ✨ Features

✅ Automatic OpenSteamTools installation  
✅ Automatic Steam folder detection  
✅ Installation of files from a built-in ZIP archive  
✅ Automatic creation of the `config/lua` folder  
✅ ZIP installation using drag & drop  
✅ Steam closing and restarting controls  
✅ Floating icon that stays above other windows  
✅ Icon size customization  
✅ Built-in user instructions  

---

## ⚙️ Installation

1. Run the program **as administrator**.

2. Press the **Install OpenSteamTools** button.

3. The program will automatically:
   - find your Steam installation folder;
   - replace the required 3 DLL files;
   - create the `config/lua` folder if it does not exist.

4. After installation, SteamTools will be ready to use.

---

## 🔒 Safety

Changing Steam files is required only for the program to work.

**SteamLuaTools does not affect your Steam account, games, save files, or personal data.**

---

## 💻 Requirements

- Windows 10 / Windows 11
- Steam installed
- Administrator privileges

---

## 📦 Installing Files Through ZIP

The program also supports installing additional files:

1. Get a ZIP archive with the required files.
2. Drag the ZIP archive directly onto the SteamLuaTools icon.
3. The program will automatically install the files into the correct folder.
