SteamLuaTools v1.0

SteamLuaTools — программа для автоматической установки и управления OpenSteamTools.

Программа предназначена для замены нерабочей версии SteamTools. Она автоматически устанавливает необходимые файлы в папку Steam, заменяет 3 DLL-файла и создаёт папку config/lua, куда добавляются игровые манифесты.

Возможности:

✅ Автоматическая установка OpenSteamTools\n
✅ Поиск папки Steam на компьютере\n
✅ Установка файлов из встроенного ZIP-архива
✅ Создание папки config/lua автоматически
✅ Поддержка установки через перетаскивание ZIP-файлов
✅ Управление Steam (закрытие и перезапуск)
✅ Удобная плавающая иконка поверх окон
✅ Настройка размера иконки
✅ Встроенная инструкция по использованию

Установка:
Запустите программу от имени администратора.
Используйте кнопку установки OpenSteamTools.
Программа заменит необходимые 3 файла в корневой папке Steam.
Если папки config/lua нет — она будет создана автоматически.

Изменение файлов Steam необходимо только для работы программы и не влияет на ваш Steam-аккаунт, игры или сохранения.

Требования:
Windows 10/Windows 11 и Установленный Steam
